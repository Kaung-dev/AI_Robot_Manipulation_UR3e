System Overview

This project investigates goal-conditioned robotic manipulation entirely in simulation, built on NVIDIA Isaac Sim 5.1 and the Isaac Lab 2.3.2 framework. A Franka Emika Panda manipulator must clear a set of tools (brush, pliers, scissors and screwdriver) from a Robotis pegboard and place each one into a basket. This is a contact-rich pick-and-place task that couples two challenges: visually identifying and localising the correct tool, and learning a control policy precise enough to grasp, carry and release it without dropping it.

Our approach deliberately decouples perception from control and is realised as a six-stage pipeline:

  1. Segmentation data collection. RGB frames with per-pixel class masks are captured automatically inside the simulator across randomised scenes and camera views.
  2. Perception (CNN). A convolutional semantic-segmentation network — a U-Net, alongside a pre-trained ResNet-18 variant — is trained on these frames to label each pixel by object class. Combined with depth and camera intrinsics, this localises every tool in 3-D, answering which tools are present and where.
  3. Expert demonstrations. A small set of successful grasps is recorded by a human operator through keyboard and VR teleoperation of the Franka arm.
  4. Demonstration augmentation. Because imitation learning is data-hungry, these ≈160 human demonstrations are amplified into over 3,000 synthetic trajectories using Isaac Lab Mimic, which re-targets each annotated grasp across hundreds of randomised object poses; the generated demonstrations are then filtered for quality.
  5. Policy learning (Behavioural Cloning). A per-tool behavioural-cloning policy — a multilayer perceptron mapping a 43-dimensional state observation to joint-space actions — is trained in a supervised manner to imitate the augmented demonstrations, with a phase variable distinguishing the approach and carry stages of each pick.
  6. Evaluation. The learned policies are run in closed-loop rollouts in Isaac Sim and assessed with task-level metrics — success rate (with Wilson confidence intervals), segmentation accuracy, and how faithfully the policy reproduces the demonstrated actions.

By integrating CNN-based computer-vision perception with imitation learning inside a single simulated robot, the system brings together two core topics of the subject and demonstrates an end-to-end, learning-driven manipulation pipeline.

Abstract

This project tackles goal-conditioned robot manipulation — given a spoken command (e.g. "pick the brush"), a Franka Panda robot must identify the correct tool among four similar-looking objects on a pegboard and place it in a basket.

We train entirely in simulation using NVIDIA Isaac Lab. A U-Net / ResNet-18 CNN is first trained on segmentation masks to give the robot visual perception. Human demonstrations are then recorded via keyboard teleoperation and expanded using Isaac Lab Mimic to generate a large synthetic dataset (≈160 human demonstrations amplified to over 3,000). A Behaviour Cloning (BC) policy is then trained on this dataset.

Results Discussion and Reflection

Overall, the pipeline succeeds end-to-end: the behavioural-cloning policies learn to perceive, approach and grasp the commanded tool, and to deposit it in the basket. The training curves show validation loss tracking the training loss and plateauing, which indicates the policies converge without over-fitting to the demonstrations. Measured over closed-loop rollouts, task success (the object landing in the basket) reaches roughly 53% for the brush, 61% for the screwdriver and 33% for the pliers. The Isaac Lab Mimic stage was central to this: approximately 160 human teleoperation demonstrations were amplified into more than 3,000 synthetic trajectories — about a thirteen-fold increase — giving the policies sufficient data to train on without additional human effort.

Reading the evaluation metrics together is more informative than any single number. The imitation-fidelity analysis shows that, for every tool, the policy reproduces the demonstrated actions more closely during the approach phase than during the carry phase, and the screwdriver — the most geometrically awkward object — is the hardest to imitate overall. This is consistent with the failures we observe in simulation: errors accumulate after the grasp rather than before it. The pliers, which achieves both the lowest success rate and the weakest segmentation of any tool, further illustrates how a perception weakness propagates downstream into control performance.

Limitations. The dominant failure mode is covariate shift during the carry phase: once the policy grasps the object it can enter states under- represented in the demonstrations, and the gripper behaviour becomes unreliable. The evaluation is also based on a modest number of rollouts per tool (roughly 9–15), so the reported success rates carry wide Wilson 95% confidence intervals and should be read as indicative rather than definitive. Finally, the entire study is conducted in simulation — the policies have not been deployed on a physical Franka Panda, leaving an open sim-to-real gap — and the segmentation model is camera- and scene-specific, so it must be retrained when the viewpoint changes.

Future work. The most direct next step is to repair the carry phase by fine-tuning the behavioural-cloning policies with reinforcement learning (PPO) under a shaped reward that explicitly rewards grasp and lift progress, mitigating the covariate shift that pure imitation cannot. Beyond this, running substantially more evaluation episodes would tighten the confidence intervals, domain randomisation and retraining would make the perception model robust across cameras and scenes, and sim-to-real transfer onto physical hardware remains the longer-term goal.

Reflection. The project demonstrates that computer-vision perception and imitation learning can be combined into a single, working manipulation system in simulation, and that demonstration-efficient learning is feasible when a small set of human demonstrations is amplified through Isaac Lab Mimic. Just as importantly, the evaluation pinpoints precisely where the system breaks down, giving a clear and well-motivated direction for the next iteration.

Installation & Running

Requirements: NVIDIA Isaac Sim 5.1.0 and Isaac Lab 2.3.2 (Python 3.11), a CUDA GPU (≥16 GB VRAM recommended), Ubuntu 22.04 or Windows 11.

Setup:

git clone https://github.com/Kaung-dev/AI_Robot_Manipulation_UR3e.git
cd AI_Robot_Manipulation_UR3e
cp .env.example .env          # set ISAACLAB_PATH to your Isaac Lab install
source .env
./setup_isaaclab.sh           # links the custom tasks into Isaac Lab

Run the trained demo — first download the models + datasets from the Data bundle into checkpoints/ and datasets/: 

./launch_air2.sh eval-sequential 10 --no_cnn

Expected result: in the Isaac Sim viewer, the Franka Panda detects the tools on the pegboard, picks them in order, and drops each into the basket.

Full step-by-step instructions — including reproducing the whole pipeline (teleop → annotate → Mimic → train BC → evaluate) — are in GUIDE.md and the README.
